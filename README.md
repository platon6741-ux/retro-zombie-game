# Zombie Siege: Retro Survival

A retro zombie survival shooter built with HTML5 canvas and Electron.

## Features
- WASD movement and mouse aiming
- Click-to-fire controls
- Weapon switching with keys 1, 2, and 3
- Zombies become stronger as the level increases
- Boss waves every 5 levels
- Ammo, medkits, and speed pickups
- Score, kills, and wave progression
- Desktop app packaging setup for Windows

## Run locally

```bash
npm install
npm start
```

## Build Windows executable

```bash
npm run dist
```

The generated `.exe` will appear in the `dist` folder.
